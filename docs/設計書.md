## 1. はじめに

本書は、`receipt-ocr-tool` の目的、構成、機能、データ、セキュリティ、運用観点を引継ぎ可能な粒度で整理する設計書である。

## 2. システム概要

レシート画像を OCR して日付・金額・店舗名を抽出し、リネームと CSV 集計を行うローカルツール

### 2.1 利用者

- 確定申告利用者
- 医療費控除整理担当

### 2.2 スコープ内

- JPG/PNG OCR
- 画像前処理
- 日付・金額・店舗名抽出
- 自動リネーム
- CSV 集計
- 手動確認フォルダ振分

### 2.3 スコープ外

- クラウド OCR
- 領収書真正性保証
- 会計ソフト直接連携

## 4. データ・設定モデル

| データ | 形式 | 説明 |
|---|---|---|
| 入力画像 | JPG/PNG | レシート画像 |
| OCRテキスト | string | 抽出処理の中間データ |
| 集計CSV | CSV | 日付、店舗、金額、ファイル名 |

## 5. 機能仕様

| ID | 機能 | 仕様 |
|---|---|---|
| F-01 | OCR | Tesseract を呼び出して画像からテキストを抽出する。 |
| F-02 | 前処理 | グレースケール・二値化などで OCR 精度を補助する。 |
| F-03 | 情報抽出 | 正規表現で日付・金額・店舗名候補を抽出する。 |
| F-04 | 整理 | ファイル名変更、CSV 出力、needs_manual_check への振分を行う。 |

## 6. セキュリティ・品質

- クラウド API を使わずローカル OCR で処理する。
- 読み取り失敗は自動確定せず手動確認に回す。

## 7. デプロイ・運用

- Tesseract と日本語言語データを事前導入
- pip install -r requirements.txt
- python main.py ./receipts --dry-run で確認

## 8. 既知の制約と今後の拡張

- 自動変換・自動判定を含む機能は、利用者または担当者レビューを前提とする。
- 本番利用前に対象データ、権限、ログ、バックアップ、例外処理を運用環境に合わせて確認する。
- README と実装差分が出た場合は、実装側を正として本書を更新する。
